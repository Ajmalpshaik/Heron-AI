# The sweep - every unproven fragment, run once, 2026-09-13

**This is a MAP, not a set of proofs.** Every DRAFT fragment was run once, positive
phase only, against one standard arrangement: 191 ducts selected in `HERONL2` of
`Snowdon-scratch_ajmal.al`, Revit 2024. No negative case was arranged, so nothing
here establishes anything under D-30.

What it establishes instead is the thing that was missing: **for each fragment, did
it run, and if not, exactly what did it ask for.** Every arrangement written before
this was derived by reading one contract at a time.

## What it changed

The backlog was being read as *"161 fragments blocked by a thin model"*. It is not.
**135 of the 147 still outstanding are blocked by a VALUE nobody had said** - a type, a
template, a folder, a distance - and each refusal names exactly which one.

That reframes the work from 147 separate puzzles into a handful of value-shaped jobs:
look a kind of value up once, then run every fragment that wants it.

## How to reproduce it

```
validate --in MODEL --out RECORD [--write] \
  --setup select-by-category-name --setup set-selection --keep-chain \
  --set categoryName=Ducts --set inViewOnly=VIEW FRAGMENT
```

**Close stdin.** With no `--negative-set`, `validate` PROMPTS at the keyboard for the
negative arrangement. Driven from a script with stdin attached, every call blocks
until it times out - 161 fragments at 120s each is five hours of nothing. With stdin
closed it reads EOF and records `skipped - NOT ESTABLISHED`, which is the honest
outcome for a survey. The whole sweep then takes **three minutes**.
