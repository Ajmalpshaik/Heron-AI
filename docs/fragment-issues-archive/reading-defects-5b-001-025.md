The collision is add-in against add-in only. **THE SWALLOW IS NOT THE DEFECT; THE SILENCE IS.** Not throwing is right — a full disk must not kill a Revit session. A hole in the evidence is now itself evidence, in the rotated log where it belongs. **AND THIS ROW'S MEASUREMENT IS A WINDOWS FACT, FOUND BY TRYING IT ELSEWHERE:** on Linux the same `FileShare.Read` holder does **not** refuse the next writer, because .NET's sharing flags are not enforced between processes there.
