### Row 5b-1526

*Moved from the register on 2026-11-17.*

**Defect.** **A FILE `EXPORT_PARAMETERS_TO_CSV` WROTE, BROUGHT STRAIGHT BACK UNEDITED, CAN BE REFUSED WHOLE BY `SET_PARAMETER_VALUES_BY_ID` - THE TWO HALVES OF ONE ROUND TRIP DISAGREE ABOUT WHAT A COLUMN MAY BE.** Read 2026-11-11 off both cards and their C# - **not run in Revit**. [`EXPORT_PARAMETERS_TO_CSV`](../../brain/fragments/export-parameters-to-csv/fragment.yaml) (FRG-PAR-017, PROVEN, version 1) says its file is written *"so the values can be edited in a spreadsheet and brought back"*. Three things it writes that the return ([`SET_PARAMETER_VALUES_BY_ID`](../../brain/fragments/set-parameter-values-by-id/fragment.yaml), all or nothing) refuses: (a) **a type parameter** - [its C#](../../brain/fragments/export-parameters-to-csv/impl/any/fragment.cs) reads the element's TYPE when the element has no parameter of that name, and writes the type's value in every instance's row; the return answers *"is on its TYPE (id N) - a row for one instance would change every other one"* and writes nothing. (b) **a read-only parameter with a value** - written out like any other; the return answers *"is read-only"*. (c) **a parameter some of the elements do not carry** - the export writes an empty cell (its own case: *"an EMPTY cell in that column, and the row still present"*); the return looks for the parameter BEFORE it looks at whether the cell is blank, so *"has no parameter called ..."* stops the file even with `blankCells=skip`. A mixed set - ducts and air terminals, one column each kind has not got - cannot come back without deleting columns. And (d) **no `UniqueId` column**: the return's check for a file from another model needs one, its card says *"export one"*, and the export has no way to write it - so a file from another model whose ids are in use here, on elements carrying every column, is not caught. Each refusal in (a) to (c) is correct and in Revit words, and none loses data. What is wrong is that nothing says so before the file is made and edited.

Was: **OPEN - recorded, not fixed; both cards are PROVEN and neither `impl/` was touched.** [`parameters-csv-round-trip`](../../brain/skills/parameters-csv-round-trip.yaml) step 1 reads which of the asked-for parameters cannot come back (`REPORT_PARAMETER_INVENTORY`) and step 3 tells the modeller which columns to delete.
