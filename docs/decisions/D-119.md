### Context

D-84 accepted that *"a runaway agent still cannot be stopped"*, and said when that was acceptable:
*"while `write.enabled` is `false` and nothing generated has ever run near a model."* D-117, once accepted,
makes the second half false on purpose.

Two things need saying apart:

- **What D-84 covers is unchanged.** It watches a newly built AGENT, Python, in the supervising process.
  It never runs a fragment, and nothing in D-117 goes through it.
- **The cost it named has a twin on the fragment side.** A fragment runs on Revit's own thread.
  `HeronStackGuard` turns runaway recursion into a finding, but a loop that never ends cannot be stopped
  from outside: the dispatcher stops waiting, and Revit stays frozen until it is ended - losing whatever
  was not saved. D-117 makes that run routine.

### The question, as it will be put

> *"A new tool that loops for ever would freeze Revit, and only closing Revit stops it. Proposal: a
> never-proved tool runs on your model only when the model is saved, so the worst case is reopening it
> and nothing is lost. (A) yes, save first - I recommend it; (B) allow it on unsaved work too."*

### Decision

1. **D-84 stands for what it covers.**
2. **Its condition is no longer the reason the cost is acceptable**, because D-117 makes it untrue. The
   cost is accepted again on a new ground: **through D-117's path a DRAFT runs only on a model that has
   been saved and has nothing unsaved** - a path on disk, and Revit's `IsModified` false. The worst a
   runaway can then cost is reopening the model from that save.
3. **The add-in refuses otherwise, before anything runs**, and says what to do: save, then ask again.
4. **No watchdog is built.** The Revit API cannot be called from another process, and a thread cannot be
   aborted on .NET 8 and later (Revit 2025 on) - so ending Revit is the only stop there is, and saving
   first is what makes it cheap.

### Consequences

- The modeller saves before asking for a DRAFT to run. A model never saved is refused, whatever
  `IsModified` says - there is no file to reopen.
- **Saving a workshared local is not a sync**, and nothing here syncs (Article 10).
