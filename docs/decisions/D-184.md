### Context

Group NK's NK8 (c) bound a "Drawn By" to views only and expected every view to be read as doubtful. Nothing carried
the name twice on one element, so `CHECK_SHEET_SETS_BY_PARAMETER` read every one, rightly (row 5b-1632). Asked how the
step should read, the owner answered with the rule behind it: a name like "Drawn By" can sit in several places in one
model.

### Decision

1. **A parameter name can live in several places in one model** - on views, on sheets, in Project Information - as a
   project parameter or a shared one. Before acting on it by name, Heron checks where it lives in that model.
2. **When more than one place carries the name, Heron asks the modeller which one before acting**, and never picks one.
3. **One element carrying the name twice is unchanged:** the readers of row 5b-203 refuse it as NOT READ.

### Consequences

- Nothing in code changed. The rule is how a chat acts on D-33; NK8 (c) now checks that a chat does it, and a chat
  that does not is a finding.
