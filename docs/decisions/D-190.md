### Context

Since 2026-10-07 the README has opened with *"Dear Modelers - please do not install this yet"*. On 2026-11-16
[D-173](../DECISIONS.md#d-173--a-release-is-versioned-and-checksummed-now-and-says-plainly-it-is-unsigned-and-is-signed-before-heron-is-given-to-anyone-outside) made taking that notice out one of two moments that wait for a signed release. The same day
v0.2.0 was published with one file to install, `HeronSetup-0.2.0-unsigned.exe`. Its release notes say what
was run on the owner's PC - the Setup installed Heron into Revit 2020, 2024, 2026 and 2027, its Python side
said READY, and Uninstall took everything back out - and what was not: Revit loading that exact build, the
*Add Heron to Claude Code* tick on a PC that is not a Heron developer's, and Revit 2021, 2022, 2023 and 2025.
No release is signed. On 2026-11-20 the owner asked for the notice to come out because Heron is mostly ready.

### Decision

1. **The notice comes out now, before a release is signed.** The README tells a modeller that Heron can be
   installed, and how, in a short Install section.
2. **It says plainly that the build is unsigned**, that Windows warns about it and how to get past the warning,
   and, in one table, what was run on the owner's PC, what is not checked yet and what was never run - the
   release notes' own account.
3. **Signing stays the bar** (D-173 point 4). It is still owed; this decision buys no certificate.

### Alternatives considered

- **Keep the notice until a signed release** - D-173 as written. Not taken: the owner's word.
- **Keep the notice and only point it at v0.2.0.** Not taken: the owner's word.

### Consequences

- **In practice Heron is offered to anyone who reads the README**, which was D-173 point 3's other moment, so
  both now come before signing. What a modeller is told is the one guard left: unsigned, and exactly what was
  and was not run.
- A modeller is told Heron starts read-only, and where to report a problem: an Issue.
- The record pages that said the notice *still stands* ([17](../17-open-source-and-distribution.md), [Group AC](../needs-checking/group-ac.md), [00](../00-master-specification.md)) get a dated line; their earlier words stay.
