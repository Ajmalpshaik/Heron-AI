### Context

The owner asked for every agent to be checked, and for one that is not needed to be retired. The check
was made on 2026-11-11 and is [row 5b-1546](../fragment-issues/section-5b-rows-401-425.md): of the agents
`python tools/agent-count.py` counts as built, **120 are called by nothing but their own command line and
their suites** (measured that day - the same finding as
[row 5b-83](../fragment-issues/section-5b-rows-076-100.md), which has asked for a sitting since
2026-09-21). Every one of them passes its suites and says `DRAFT`, and the
specifications' as-built notes already say *"no tool reaches it"* of most of them, so no sentence about
them is wrong.

**The house has three ways for an agent to stop being work, and retirement is the one never used.** A
row is the **host's** ([D-01](../decisions/D-01.md),
[D-80](../decisions/D-80.md)); or it is **folded or
deferred** by a decision that names it
([D-76](../decisions/D-76.md),
[D-77](../decisions/D-77.md),
[D-78](../decisions/D-78.md)); or it is
**retired** by [`heron_retirement.py`](../../brain/heron_retirement.py), which asks for a reason, a
person's name and - while any other file still names the agent - a successor, and which nothing has
ever called: no source file says `DEPRECATED`.

**"Nothing calls it" is not "not needed".** The agent operating system was adopted whole
([D-11](../decisions/D-11.md)) and most of these are a seam
whose customer is a later phase - the specification's own as-built notes say of the workflow engine,
the scheduler and the Fix Agent only that no tool reaches them
([00](../00-master-specification.md), [00c](../00c-master-handover-baseline.md)). Retiring on the first
half alone would retire the Session Rollback, the Safe Mode and the Update agents for having had nothing
to do yet.

### Decision

1. **The test has two halves, and both are measured.** *(a) Nothing calls it:* no tool the MCP server
   serves, no entry class of the add-in or the installer, no script in `tools/`, no hook, no CI workflow
   and no command a house rule tells a session to run reaches a function of it. Its own command line and
   its suites do not count. *(b) A named thing already does its job, or a named decision took the job
   away.* **(a) alone is waiting, and a waiting agent stays.**
2. **The owner signs, by name, per agent or per named group.** The rule is
   [`heron_retirement.retire()`](../../brain/heron_retirement.py)'s: a reason, a person, and a successor
   where another file still names the agent. A Heron agent or an AI session never signs
   ([Golden Rule 7](../14-golden-rules.md)).
3. **What a retirement changes, and nothing else.** The implementing file's `Heron-Status` header goes
   from `DRAFT` to `DEPRECATED`; its register row stays and says **RETIRED** with the date, this
   decision and what does the job instead; the file, its contract and its suites stay, and the suites
   go on running - retired code still has to load. **Nothing is deleted**
   ([Article 1](../../HERON_CONSTITUTION.md)), so a retirement is undone by one header and one row.
4. **`agent-count.py` learns the state first.** Today it knows BUILT, HOST, DEFERRED and LEFT, and a
   retired agent is none of them: counted BUILT it would look like work that is held, counted LEFT like
   work that is owed. The fifth state is read from the row, the way DEFERRED is, and is added in the
   change that retires the first agent - not before, and not by this decision.
5. **An add-in agent with a signed proof is not retired by its header** until
   [row 5b-1340](../fragment-issues/section-5b-rows-401-425.md) is settled: editing the header stales the
   proof.

### Consequences

- **Until this is accepted nothing changes**, and after it nothing changes without a name on it.
- **Keeping an uncalled agent has a cost, and it was measured**: two command lines that raised and one
  baseline that had not matched the tree for twenty-five days, none seen, because nothing runs them
  ([rows 5b-1544 and 5b-1545](../fragment-issues/section-5b-rows-401-425.md)). A waiting agent is held by
  its suite and by nothing else.
- **Retiring one has a cost too**: the specifications' as-built notes name these files, and each note
  would say *retired* instead of *no tool reaches it*.
- **The list is a measurement, not a register.** `python tools/module-reach.py --list` is the standing
  command - it reads imports, per module, in `brain/`
  ([row 5b-83](../fragment-issues/section-5b-rows-076-100.md)). The table above was made per agent, by
  function, by rough work that is not in the repository; the two agree on the size of it.
