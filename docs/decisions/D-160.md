### Context

A change asked to keep - a rename that matched nothing, a set that found the value already set - was
assimilated even when Revit counted no element added, changed or deleted. That left an empty
`Heron: <name>` entry in the modeller's undo list. Row 117 named the hazard: told to press Ctrl+Z for a
change that did nothing, a modeller undoes whatever they did **before** it.

### Decision

1. **A keep is rolled back instead of assimilated when Revit's own change report arrived, was read whole
   (`Witnessed`) and counted zero - setup steps included.** Decided after the report is read and before
   Assimilate.
2. **Never for a publish.** What an export, a save or a sync sent out is outside the model and outside
   Revit's count.
3. **A report that saw no event at all keeps as before.** Silence is not "nothing changed"
   (`HeronChangeReport.Witnessed`).
4. **Its own verdict, kind `unchanged`:** *"NOTHING CHANGED, SO NOTHING WAS KEPT ... there is NO new entry
   in Revit's undo list, and Ctrl+Z would undo whatever was done before this."* Never the plain
   rollback's *"send it again with apply"* - it was sent with apply. The activity list reads it as ROLLED
   BACK; the run record says *nothing changed, nothing kept - no undo entry*.
5. No read-back is attached (D-156): an empty keep rolled back is not a dry run.

### What is not known

Nothing of it has run in Revit; it compiles for 2020 to 2027 and `tests/test_empty_keep.py` checks the
wiring and the server's words, failing on the code before the change. **Whether Revit raises a committed
event, with no ids, for a transaction that changed nothing** decides whether rule 1 ever fires - if it
raises none, the keep is unwitnessed and kept as before. [NEEDS-CHECKING Group NW](../needs-checking/group-nw.md).

### Alternatives considered

- **Leave the empty entry and keep warning in words** - row 117's conditional Ctrl+Z sentence. It is still
  there for a keep that is not witnessed; where Revit's count is known to be zero, removing the entry is
  better than describing it.
