### Context

Article 19: *"No agent approves itself. The agent that creates is never the agent that validates. The
agent that implements is never the agent that tests."* Under D-117 the agent that wrote a fragment is the
one able to start its first run. That reads as the creator testing its own work unless it is said who
judges.

### The question, as it will be put

> *"The agent that writes a new tool would also be the one that starts its one run on your model. The
> judging stays yours: only you can press Keep, and the agent never signs a proof or raises a tool's
> status. Is that within 'no agent approves itself' (A - I recommend it), or must a different agent start
> the run (B)?"*

### Decision

1. **The validator of a DRAFT's one run is the modeller, in Revit.** Keep, pressed after seeing the
   result, is the judgement - and only a person can give it, because the box is modal in Revit and
   nothing on the wire answers it.
2. **The author agent may start the run: once per version, only when the modeller asks for it in the
   chat, and only through `try-once`** - never through `revit_change`, `fragment --apply` or anything else.
3. **The author never treats the outcome as a verdict on its own work.** It reports what Revit said and
   what the modeller chose, and stops. It does not run the negative case, does not draft, does not sign,
   and never moves `heron-status`. Those are the proving session's: the Fragment Validation Agent
   (`HERON-FRG-VAL-001`) and a person's name.
4. **Compiling and the routing checks stay the author's.** They show the code is well formed; whether it
   does the job on a building is the modeller's and the proof's.
5. **"Only when the modeller asks" is a rule on the agent, not enforced in code.** The prompt after the
   run is the human gate that is enforced. A question in Revit before a DRAFT runs is separate work.

### Consequences

- `.claude/agents/heron-fragment-author.md` and `.codex/agents/heron-fragment-author.toml` say this in
  place of *"You never run it"*, and its tool list is unchanged: no Heron tool on it reaches Revit
  ([`tests/test_agent_tools.py`](../../tests/test_agent_tools.py) holds that).
