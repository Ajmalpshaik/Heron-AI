### Context

Item 7 of the build order in [research note 51](../51-studying-another-revit-mcp.md) is *"many models overnight,
read only - one report at the end"*: point Heron at a project folder, open each model, run the QA checklist,
close it without saving, and give one report in the morning. Checking it against Heron before building found two
questions only the owner could answer ([Q-93](../open-questions/tier-3.md)): where the models open, and whether
opening another project file is a read or needs Publish, as `UPGRADE_FAMILY_FILES` does because it saves what it
opens.

### Decision

1. **The models open in the one Revit the modeller connected Heron to, one model at a time** - opened in the
   background, read, and closed without saving. Never a separate Revit started for each model, and never a Revit
   the modeller did not give to Heron.
2. **Opening a model read-only, reading it and closing it without saving is a read.** It is allowed with Changes
   off; Publish is not needed, because nothing is saved anywhere.
3. **Nothing is built by this decision.** The overnight folder check is a later build job of its own, started when
   the owner asks for it. These two answers are what it starts from.

### Alternatives considered

- **A separate Revit for each model**, run by a small helper program that survives a crash. Not taken: the owner
  connects Heron to one Revit and wants the work done there. It was also the much larger build, held a licence per
  model, and could not run unattended while Revit asks *Load or not* for an unsigned add-in ([Q-77](../open-questions/tier-2.md)).
- **Opening counts as Publish.** Not taken: nothing is written to the model or to any file by opening and closing
  without saving.

### Consequences

- The modeller's Revit is busy for the whole run, a dialog a model raises on opening stops that model, and one very
  large model can outlast the run clock - the costs Q-93 named for this shape, for the build to handle.
- Whatever the build opens is watched by the run guard like any other document a job opens.
- Not run in Revit, because nothing was built.
