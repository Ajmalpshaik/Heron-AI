### Context

D-30 asks every proof for a second leg that comes back empty. `REFRESH_VIEW` takes no input and the add-in
always gives it a screen, so its one prescribed negative cannot be arranged. `REPORT_LEVEL_ELEVATIONS` always
writes a line, even *"this model has no levels"*, and its only input is the `includeLinks` switch. Neither has a
leg that can come back empty (row 5b-1969).

Separately, batch proving keeps one run record and one draft per tool, so a second run of the same tool replaces
the first. Three tools had more than one run waiting: `CREATE_SHEETS` (Group OZ's table run, written for version 4,
and Group PE's placeholder run of version 5), `EXTEND_ROOF_TO_ROOF` (three job files, two releases), and the Group
OK pair `CREATE_LINE_STYLE` and `SET_FAMILY_PLANE_REFERENCE` (unsigned drafts already on the owner's PC) - row 5b-1978.

### Decision

1. **`REFRESH_VIEW` and `REPORT_LEVEL_ELEVATIONS` are signed on a by-hand reading in place of the empty leg.** The
   owner watches the tag change on screen for Refresh view, and reads the storeys line against Manage > Levels for
   Report level elevations. The reading is written on the proof with the Revit release, the model and the date. The
   positive run is still a recorded run as D-30 asks.
2. **A tool with more than one run waiting is signed on the run that was actually checked in Revit, for the tool as it
   stands.** Whatever Revit check a tool still needs is run, its draft read, and then it is signed PROVEN by the owner.
   Two runs of the same tool are never left waiting at once: the draft of one is read and signed or set aside before
   the next run of that tool. For `CREATE_SHEETS` that is version 5's run; `EXTEND_ROOF_TO_ROOF`'s other releases run
   with `--release`; the Group OK drafts already on the PC are reviewed before any new OK run.

### Consequences

- Both tools can go into a batch job; the proof's negative cell carries the by-hand reading, not a run.
- No AI session signs either. The signature stays the owner's.
- Nothing in code changes with this decision.
