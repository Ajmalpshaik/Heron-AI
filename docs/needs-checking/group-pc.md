**The models: scratch copies, never a working model.** A scratch copy of a sample project in
`%TEMP%\heron-work\pc`, pinned in the chat, with an empty folder `%TEMP%\heron-work\pc\out` for the files the
scratch cards write. The scratch cards below are written in `%TEMP%\heron-work\pc\cards`, never in Heron's
folder, and sent with `python mcp/client/heron_bridge_client.py fragment ... --write` (or `validate --write
--allow-publish`) from a terminal, so the reply is read whole - an Admin or Publish card goes as its own
operation by its declared risk. Publish on for PC1, Admin on for PC2. Read the document name on every reply.
