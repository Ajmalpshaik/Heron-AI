## F42 — the HVAC design engine leaves five things only the owner can settle

### 🟠 F42. The HVAC design engine leaves three decisions for the owner - figures offered, a friction fragment, skills (the standards and the neck velocity were answered 2026-10-02 as D-111 and D-110)

Raised 2026-10-02 with [`HERON-MEP-HVD-001`](../../brain/heron_hvac.py), the HVAC design engine built on the
owner's request and described in [41](../41-hvac-design.md). It is built and tested for arithmetic; these
five are decisions, not gaps, and [41 §15](../41-hvac-design.md) carries the reasoning for each.

1. **A standard's figure is shown beside the question it answers.** The engine never applies one -
   [D-33](../decisions/D-33.md) holds - but a missing outdoor-air rate comes back with *"62.1-2022 Table 6-1
   gives 2.5 L/s per person for office space - offer it, do not assume it"*. Keep showing the figure,
   or show only the table's name?
2. **Which standards govern a Qatari project** - which edition of ASHRAE 62.1, whether ASHRAE 90.1
   applies, CIBSE beside ASHRAE, the QCS 2014 or 2024 condition - could not be established from any
   source this work could read. Ask once per project and remember it, as D-33's *asks once* allows?
   **✅ Answered 2026-10-02 - yes, as [D-111](../decisions/D-111.md):** *"ask standards once per
   project"*. The four are asked together, never block a calculation, and are kept for that project
   only.
3. **A fragment that sizes ducts by friction inside Revit.** Today the host reads the flows, the engine
   sizes them and `SET_MEP_SIZE` writes each size group. A fragment would do it in one call, and would
   carry the same arithmetic in C# - a second home for one fact.
4. **Skills cannot name the engine.** A skill names capabilities, which fragments provide; this is an
   MCP tool. Should `space-airflow`, `terminal-layout` and `duct-layout` reach it, and how?
5. **The owner's own AJ-Tools knowledge file puts a supply diffuser's neck at 2.5 m/s for NC/RC 30**;
   ASHRAE HVAC Applications (2019) Ch. 49 Table 9, as transcribed, gives 2.2 m/s supply at RC 30 - 2.5
   is RC 35, or a return at RC 30. Which governs? Recorded in [41 §12](../41-hvac-design.md), not resolved.
   **✅ Answered 2026-10-02 - 2.5 m/s, as [D-110](../decisions/D-110.md):** *"Use 2.5 m/s"*. Held to a
   supply neck in an NC/RC 30 room, named as the office's own figure wherever it is used.

**Two of the five are answered** (2 and 5, above). Items 1, 3 and 4 are still the owner's.
