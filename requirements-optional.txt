# Heron - what the Python side can USE, and works without.
#
#     pip install --user -r requirements-optional.txt
#
# In plain words - what every PC needs for Heron, and what is optional:
#     docs/WHAT-TO-INSTALL.md
#
# Read what each buys before installing it:
#
#     python tools/check-dependencies.py
#
# Every package here degrades rather than breaks - that is the rule these
# entries have to keep, not a description of today's luck. Heron answers
# with none of them installed, and says which one did not run.
#
# Same comment shape as requirements.txt:
#     # <import name> | <what Heron uses it for> | <what happens without it>
#
# NO SIZES ARE WRITTEN HERE. Where the size is known it is stated by the
# code that owns the download - heron_ingest says it in the error a reader
# actually hits. A number repeated here is a number that goes stale there.

# NO SEARCH ADD-ON IS LISTED. model2vec (a trained embedding) and
# huggingface-hub, which only it needed, were here until D-203 (2026-11-26)
# removed them: Heron has one search, built in, the same on every PC.
# docs/WHAT-TO-INSTALL.md says what to remove from a PC that has them.

# sqlite-vec is NOT listed: every stored vector is compared in plain Python
# and nothing in Heron loads it (D-194, 2026-11-21). It was here until then.

# (2026-11-26) removed it: no clear gain, and the largest download on this
# list. docs/WHAT-TO-INSTALL.md says what to remove.
